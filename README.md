## Open Source — InsForge Contribution

**[InsForge](https://insforge.dev)** is a YC-backed open-source BaaS platform. I contributed a complete Razorpay payment provider integration — one of the platform's largest third-party contributions.

| Scope | Details |
|-------|---------|
| **Feature** | Razorpay as a production-grade payment provider alongside Stripe |
| **Infrastructure** | HMAC webhook verification · PostgreSQL advisory locking · idempotency keys |
| **Sync Engine** | Products · Customers · Subscriptions · Payment History |
| **Security** | Secure secret management · environment-specific runtime config |
| **Scale** | 30+ commits · ~3,000 lines · merged into v2.2.1 |
| **Recognition** | InsForge published a [dedicated release blog post](https://insforge.dev/blog/insforge-razorpay-integration) crediting this contribution |

`TypeScript` · `Node.js` · `React` · `PostgreSQL` · `Docker` · `Razorpay`

→ [View Pull Request](https://github.com/InsForge/InsForge/pull/1382)
